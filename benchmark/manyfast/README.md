## 녹화 중 확인한 사실

- **생성 순서**: PRD → 요구사항 → 정책 → 기능 → 상세기능 → 유저플로우 → 와이어프레임.
- **편집 반영 방식**: AI가 고친 내용은 섹션 카드로 승인·거절하고, 일괄 승인도 된다.
- **기능 상세 9슬롯**: 선행조건 · 트리거 · 동작 · 결과 · 예외 · 표시 · 권한&접근 · 비즈니스 규칙 · 데이터.
- **미정 슬롯**: 선택지·추천·직접 입력이 있는 질문 카드로 문서 안에 남는다.
- **정책 연결**: 정책마다 ID가 있고, 연결된 요구사항·기능·상세에 "영향받음"을 표시한다.
- **검토**: 관점 6개 중 Starter는 개발만 쓸 수 있다. 1회 약 800크레딧.
- **회의록**: 결정을 확정·미정으로 나누고, 확정 결정은 기능 ID·필드 단위로 반영 문구를 제안한다.
- **와이어프레임**: 유저플로우의 페이지 노드로 만들고, 섹션별로 묶이며, 클릭 가능한 프로토타입이 된다.
- **동기화**: 기준 문서 하나를 골라 대상 문서들의 누락·충돌을 고친다.
- **내보내기**: PRD는 md·텍스트·엑셀, 기능명세서는 엑셀·이미지·md·텍스트, 유저플로우는 이미지·Mermaid, 와이어프레임은 이미지·HTML·Figma. Starter는 3회까지.
- **커넥터**: ChatGPT · Claude · Codex · Claude Code · Antigravity · Cursor · Lovable, Linear·GitHub·Jira·monday(Pro), 기타 MCP.
- **커스텀**: 출력 언어, 대화 말투, 기획서 문체·기능 설명 양식·팀 용어·하지 말아야 할 것·기타(Pro).
- **버전**: 자동 저장, AI 편집 전 자동 백업, 수동 저장. 작업 로그는 Pro.

## 막혀서 못 본 것

- **와이어프레임 신규 생성**: 무료분 0장, 업그레이드가 필요하다. 이미 생성된 청첩장 프로젝트로 대신 녹화했다.
- **PRD 양식 편집, 검토 5개 관점, 작업 로그**: Pro 전용이다.
- **AI 질문 인터뷰 카드(Q1/3)**: 새 프로젝트는 첫 생성 오류 뒤 재시도로 바로 PRD가 생성됐다. 질문 카드는 기존 청첩장 프로젝트 채팅 기록에서 확인했다.
