# 게시글 수정 기획

상태: 확정

## 페르소나

### P1 글을 자주 올리는 작성자

동네 소식을 하루에 두세 번 올리는 사람이다.

원하는 것
- 오타를 발견하면 바로 고치고 싶다.
- 고쳐도 댓글은 그대로 남았으면 좋겠다.

행동 패턴
- 글을 올린 직후 휴대폰으로 다시 읽어 본다.

불편
- 고치려면 지우고 다시 올려야 한다.

## 요구사항

### R1 작성자는 올린 글을 고칠 수 있다

누구: P1
근거: BR1
우선순위: P1
왜: 오타를 발견하면 바로 고치고 싶다.

완성 기준
- R1-1 작성자는 자기 글에서 고치기를 시작할 수 있다.
- R1-2 고친 뒤에도 댓글이 그대로 남는다.
- R1-3 고치던 중에 닫으면 고친 내용을 버릴지 먼저 묻는다.
- R1-4 [제외: 다음 분기에 한다] 고친 기록을 다른 사람이 볼 수 있다.
