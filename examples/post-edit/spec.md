# 게시글 수정 기획 상세 스펙

상태: 확정

## 상태표

| 대상 | 상태 | 뜻 |
|---|---|---|
| 게시글 | 게시됨 | 모두에게 보이는 글이다 |
| 게시글 | 잠김 | 신고가 쌓여 관리자가 막은 글이다 |

## 조건표

| 조건 | 갈래 | 정해지는 곳 |
|---|---|---|
| 수정 권한이 있는가 | 예, 아니오 | 글쓴이 본인이면 예다 |
| 고친 내용이 있는가 | 예, 아니오 | 모달을 연 뒤 한 글자라도 바뀌면 예다 |

## 진행표

| 단위 | 이름 | 요구사항 | 진행 |
|---|---|---|---|
| F1 | 게시글 수정 | R1 | 완료 |
| FN1 | 수정 중 닫기 | R1 | 완료 |

## F1 · 게시글 수정 · R1

| 항목 | 내용 |
|---|---|
| 목적 | 작성자가 올린 글을 지우지 않고 바로 고친다 |
| 행위자 | P1 |
| 시작 | 사용자가 자기 글의 게시글 상세 화면을 연다 |
| 사전 조건 | 사용자가 로그인해 있다 |
| 기본 흐름 조건 | 수정 권한이 있는가: 예, 게시글 상태: 게시됨 |
| 성공 결과 | 고친 글이 보이고 댓글은 그대로 남는다 |
| 실패 시 보장 | 저장하지 못하면 원래 글이 그대로 남는다 |

### 기본 흐름

- 1. 사용자가 수정을 누른다
- 2. 수정 모달이 열린다
- 3. 사용자가 글을 고치고 저장을 누른다
- 4. 고친 글이 보이고 댓글은 그대로 남는다

### 대안 흐름

- 1a. 수정 권한이 있는가: 아니오
  - 1a1. 수정 단추가 보이지 않는다
  - 1a2. 끝난다
- 1b. 게시글 상태: 잠김
  - 1b1. 수정 단추가 비활성이다
  - 1b2. 끝난다
- 3a. 사용자가 저장하지 않고 닫기를 누른다
  - 3a1. FN1 수정 중 닫기를 따른다

### 예외 흐름

- 3b. 저장이 실패한다
  - 3b1. 저장되지 않았다는 안내가 뜬다
  - 3b2. 2로 돌아간다

## FN1 · 수정 중 닫기

| 항목 | 내용 |
|---|---|
| 목적 | 고치던 중 닫을 때 고친 내용을 실수로 잃지 않게 한다 |
| 기본 흐름 조건 | 고친 내용이 있는가: 예 |

### 기본 흐름

- 1. 사용자가 닫기를 누른다
- 2. "저장하지 않고 닫을까요?" 확인창이 뜬다
- 3. 사용자가 확인창에서 닫기를 누른다
- 4. 모달이 닫히고 고친 내용은 버려진다

### 대안 흐름

- 1a. 고친 내용이 있는가: 아니오
  - 1a1. 모달이 바로 닫힌다
  - 1a2. 끝난다
- 3a. 사용자가 확인창에서 취소를 누른다
  - 3a1. 모달이 그대로 남는다
  - 3a2. 끝난다
