# 게시글 수정 기획 상세 스펙

상태: 확정

## 상태표

| 대상 | 상태 | 뜻 |
|---|---|---|
| 게시글 | 게시됨 | 모두에게 보이는 글이다 |
| 게시글 | 잠김 | 신고가 쌓여 관리자가 막은 글이다 |

## 조건표

| 조건 | 갈래 | 정해지는 곳 |
|---|---|---|
| 수정 권한이 있는가 | 예, 아니오 | 글쓴이 본인이면 예다 |
| 고친 내용이 있는가 | 예, 아니오 | 모달을 연 뒤 한 글자라도 바뀌면 예다 |

## 진행표

| 단위 | 이름 | 요구사항 | 진행 |
|---|---|---|---|
| F1 | 게시글 수정 | R1 | 완료 |
| FN1 | 수정 중 닫기 | R1 | 완료 |

## F1 · 게시글 수정 · R1

- [게시글 상세] 진입
- ? 수정 권한이 있는가
  - **아니오**
    - → [수정] 단추가 보이지 않는다
  - **예**
    - ◆ 게시글 상태
      - **게시됨**
        - [수정] 누름 → 수정 모달이 열린다
        - [저장] 누름 → 고친 글이 보이고 댓글은 그대로 남는다
        - ↪ FN1 수정 중 닫기
      - **잠김**
        - → [수정] 단추가 비활성이다

## FN1 · 수정 중 닫기

- [닫기] 누름
  - ? 고친 내용이 있는가
    - **아니오**
      - → 모달이 바로 닫힌다
    - **예**
      - → "저장하지 않고 닫을까요?" 확인창이 뜬다
      - [닫기] 누름 → 모달이 닫히고 고친 내용은 버려진다
      - [취소] 누름 → 모달이 그대로 남는다
