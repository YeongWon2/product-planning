PRD

무엇을 왜 만드나

해결할 문제

관리자가 항목을 배정해도 담당자가 받았는지 확인할 방법이 없다 예시 기획 문서 1장

대상 사용자

  • 배정 관리자 담당자에게 항목을 빠짐없이 배정한다
  • 담당자 배정된 항목을 제때 처리한다

목표 지표

  • 주간 배정 완료율 측정: 항목 배정 완료

요구사항

우선순위요구사항누가

시나리오

누가 어떤 순서로 하나

관리자가 항목을 배정한다

  • 항목 배정 · 기본 흐름 기본 흐름 배정 관리자 · 3단계

완료 조건

  • 상황 '배정 관리자'가 '항목 목록' 화면에 있을 때 행동 제목과 담당자를 넣어 '항목 만들기'를 마치면 결과 '진행 중' 항목이 목록에 추가되고 담당자 앱에 알림이 간다

관리자가 항목을 마감한다

  • 항목 마감 · 기본 흐름 기본 흐름 배정 관리자 · 4단계

완료 조건

  • 상황 '배정 관리자'가 '진행 중' 항목의 상세 화면에 있을 때 행동 '항목 마감하기'를 누르고 확인하면 결과 항목이 '완료' 상태가 된다
